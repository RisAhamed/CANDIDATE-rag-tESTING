[00:11:15]
CANDIDATE: We use several strategies. First, we use a strict system prompt that instructs the model to only use provided context. Second, we implement a confidence threshold - if the model's response has low token probability, we flag it for review. Third, we use citation generation so users can verify claims against source documents. Finally, we have a feedback mechanism where users can flag incorrect answers.
